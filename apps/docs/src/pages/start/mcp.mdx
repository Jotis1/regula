Regula tiene un servidor MCP remoto en `https://regula.jotis.me/mcp`. Es solo de consulta: no escribe nada, no pide cuenta ni clave y no llama a otros servicios. Responde con lo mismo que publica esta web, así que una norma, una prop o un token son los de la guía y no una copia.

## Conectar desde Claude Code

<Code code={"claude mcp add --transport http regula https://regula.jotis.me/mcp"} />

Después, `/mcp` dentro de Claude Code enseña `regula` entre los servidores conectados.

## Otros clientes

Cualquier cliente que hable Streamable HTTP se conecta con la URL. Si se configura con un JSON, este es el formato de `.mcp.json` de Claude Code; en otros clientes cambia el nombre de las claves.

<Code
	code={`{
	"mcpServers": {
		"regula": {
			"type": "http",
			"url": "https://regula.jotis.me/mcp"
		}
	}
}`}
/>

## Herramientas

Los nombres de las herramientas y de sus parámetros van en inglés. Lo que devuelven son los textos de la guía, en español, y cada resultado trae la URL de su página.

## Versión del contrato

Las herramientas, sus parámetros y la forma de estos JSON son un contrato con versión propia, que no es la de los paquetes: ahora es la <strong>{API_VERSION}</strong>. El servidor la anuncia al conectar y cada JSON la lleva en `apiVersion`.

Sigue SemVer. Añadir una herramienta, un parámetro opcional o un campo sube la menor. Quitar o renombrar algo, o cambiar lo que significa, sube la mayor, y antes pasa al menos una menor marcado como deprecado, con `Deprecated: use …` en su descripción, y sigue funcionando.
