name: FeaturedIcon
description: "Icono dentro de una forma, para encabezar modales, alertas, estados vacíos y tarjetas."
interactive: false
---

**Props.** `icon`, `color` (`brand` · `gray` · `success` · `warning` · `error`), `size` (`sm` 32 · `md` 40 · `lg` 48 · `xl` 56), `variant`: `light` (círculo tintado; por defecto), `gradient` (círculo sólido con dos anillos tintados), `dark` (cuadrado del color sólido con el icono en blanco), `modern-neue` (cuadrado blanco dentro de un marco, con sombra), `modern` (cuadrado blanco con sombra esqueumórfica, para estados vacíos), `outline` (anillos concéntricos, para alertas).

**Regla.** El color debe coincidir con el significado del contenedor: un modal de borrado lleva `error`.
