Etiqueta de estado o categoría de una o dos palabras, junto a un nombre o en una celda de tabla.

**Props.** `color` (`gray` · `brand` · `success` · `warning` · `error` · `slate` · `sky` · `blue` · `indigo` · `purple` · `pink` · `orange`), `type` (`pill` redonda · `badge` `radius-md` · `modern` blanca con sombra), `size` (`sm` 22px · `md` 24 · `lg` 28), `dot`, `onRemove`.

**Colores.** Usan la escala utility: fondo `-50`, borde `-200`, texto `-700`, punto `-500`. El estado no debe depender solo del color: la palabra ("Pagado", "Vencido") es obligatoria.

**No.** Nada de frases. Si necesitas más de tres palabras es un `Alert` o un texto de apoyo.
