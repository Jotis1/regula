Chip neutro para filtros aplicados, etiquetas editables o selecciones múltiples.

**Props.** `size` (`sm` · `md` · `lg`), `count`, `dot`, `onRemove`, texto en `children`. Fondo `bg-primary`, borde `border-primary`, `radius-md`.

**Badge o Tag.** Badge informa de un estado y lo pone el sistema; Tag lo pone o lo quita el usuario.
