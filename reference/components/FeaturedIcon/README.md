Icono dentro de una forma, para encabezar modales, alertas, estados vacíos y tarjetas.

**Props.** `icon`, `color` (`brand` · `gray` · `success` · `warning` · `error`), `size` (`sm` 32 · `md` 40 · `lg` 48 · `xl` 56), `variant`: `light` (círculo tintado; por defecto), `modern` (cuadrado blanco con sombra esqueumórfica, para estados vacíos), `outline` (anillos concéntricos, para alertas).

**Regla.** El color debe coincidir con el significado del contenedor: un modal de borrado lleva `error`.
