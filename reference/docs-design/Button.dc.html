Cuándo usarlo

Úsalo así

  • Una sola primary por vista o por modal: la acción que esperas que hagan.
  • El resto, secondary. Lo de poco peso (cancelar en barras, ver más), tertiary.
  • Dentro de un texto o de una alerta, link-color o link-gray.
  • Texto con verbo: "Guardar gasto", no "Aceptar".

Evita

  • Apilar dos primarios. Si dudas cuál es el bueno, el usuario también.
  • El rojo para todo lo negativo. Si borrar es una opción más, secondary normal.
  • Cambiarle la forma. Un botón tiene que parecer un botón.

Destructivo como acción principal

¿Eliminar este gasto?

Se borra para siempre. No hay papelera.

Cancelar Eliminar gasto

El único caso en el que destructive va con primary: el botón que confirma el borrado.

Código

Isla en Astro. Un Button que solo navega o envía un formulario se pinta en el servidor, sin JavaScript. Si le pasas onClick o estado, móntalo con client:load o, si está bajo el pliegue, client:visible.
